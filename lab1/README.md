# Лабораторная работа 1

ЛП-модель закупки упаковки у пяти поставщиков. Вариант 11, группа Б24-517, N = 21, seed = 10121.

Минимизируются недельные затраты при ограничениях на квоты поставщиков и потребности в четырёх видах упаковки. Задание со звёздочкой — решение двойственной задачи, проверка равенства целей и экономическая интерпретация двойственных переменных.

## Установка и запуск

Команды ниже выполняются из каталога `lab1`. Из корня репозитория сначала перейдите в него:

```bash
cd lab1
```

```bash
python -m pip install -r requirements.txt
python main.py
```

В PyCharm откройте корневой каталог `linear_programming`, выберите интерпретатор и запустите `lab1/main.py`.

Для выбора сценария с клавиатуры:

```bash
python main.py --interactive
```

Пример отдельного расчёта:

```bash
python main.py --data data/variant11.json --scenario deficit --output results_deficit
```

Данные читаются из JSON. В нём можно изменить цены, потребности и квоты; неверные размеры, отрицательные объёмы и неположительные цены отклоняются. Цены задаются в тыс. руб. за тыс. шт., объёмы — в тыс. шт. за неделю. Программа выводит статус, стоимость, план закупок и результат независимой проверки. При несовместимости вместо плана выводится причина дефицита.

## Данные и результаты

Исходные данные — `data/variant11.json`. Порядок генерации и допущения описаны в отчёте. Повторная генерация:

```bash
python data_io.py --number 21 --group 517 --year 26
```

После запуска результаты сохраняются в `results`:

- `scenarios.csv` — сравнение трёх сценариев;
- в `base`, `deficit`, `stress` — входные данные сценария, статус и лог HiGHS;
- для допустимых сценариев: `solution.csv`, `constraints.csv`, `verification.json`, `shadow_prices.csv`, `dual_result.json`, `dual_verification.json`;
- для несовместимого сценария: `infeasibility.json`;
- `marginal_checks.csv` — повторные решения при увеличении каждого лимита или потребности на 1 тыс. шт.;
- `capacity_curve.csv`, `figures` — изменение затрат при изменении квоты П1 и графики;
- файлы `.lp` — модели, переданные солверу.

Столбцы CSV разделены запятыми; кодировка UTF-8 с BOM. Повторный запуск обновляет результаты выбранных сценариев. Числа в CSV сохраняются без округления до разрядности отчёта.

## Реализация

`data_io.py` читает и генерирует данные, `model.py` строит и решает обе ЛП, `verification.py` отдельно проверяет исходные ограничения на NumPy, `experiments.py` проводит сценарные эксперименты. `main.py` обрабатывает ввод и сохраняет результаты. Используется двойственный симплекс-метод HiGHS с presolve. Время зависит от компьютера; оно не используется как оценка качества алгоритма.

Отчёт — `report.md`. График в отчёте создаётся при запуске `python main.py`.

Проверки программы:

```bash
python -m unittest -v
```

Проверяются допустимость и оптимальность, обнаружение ошибок в плане и цели, несовместимость стрессового сценария, воспроизводимость данных, локальная теневая цена и альтернативный оптимум.
