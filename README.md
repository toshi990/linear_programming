# Методы оптимизации и линейное программирование

Группа Б24-517, N = 21, вариант 11.

## Лабораторная работа 1

[Закупка упаковки у поставщиков](lab1/README.md). [Отчёт](lab1/report.md).

Установка зависимостей и запуск из корня репозитория:

```bash
python -m pip install -r lab1/requirements.txt
python lab1/main.py
```

Выбор сценария с клавиатуры:

```bash
python lab1/main.py --interactive
```

Проверки:

```bash
python -m unittest discover -s lab1 -v
```

В PyCharm откройте каталог `linear_programming` и запустите `lab1/main.py`. Данные и результаты первой лабораторной находятся в `lab1/data` и `lab1/results`.
